# 新闻 + 异动信息规划（CHG-014）

> 状态：**已实现**（见 `docs/dev/变更申请.md` CHG-014）。
> 目标：帮用户了解市场情况。

## 用户已确认的决策（含二次修订）

| # | 决策点 | 选择 |
| --- | --- | --- |
| 1 | 新闻源 | **A：财联社电报**（C15 灰色区域，仅本地自用） |
| 2 | 股票异动范围 | **自选/持仓相关优先 + 全市场情绪概览** |
| 3 | LLM 参与 | **纯规则标题列表**（不用 LLM） |
| 4 | 新闻位置/存储 | **修订**：新闻不集成进日报，改独立「新闻快讯」入口；「盘中刷新/盘后汇总」两键；只存标题/时间/链接（不存正文），当日累积 |

## 功能 A：异动观察（进日报）

- 日报「市场概况」段下新增「**异动观察**」子块：
  1. 全市场情绪概览：涨停/跌停家数、最高连板。
  2. 板块领涨 Top5 / 领跌 Top5。
  3. 龙虎榜净买额居前 Top5。
  4. 自选/持仓相关异动（涨停/跌停才列）。
- 措辞固定「情绪观察，非荐股」（C1.2/C7）；盘后采集（C10）。

## 功能 B：新闻快讯（独立入口，与日报并行）

- 首页新增「📰 新闻快讯」入口 → `/news` 页，**两个生成键**：
  - **盘中刷新**：抓最新快讯（盘中使用）。
  - **盘后汇总**：抓取 + 按 id 去重累积 → 显示当日全天要闻（加红优先 + 自选/持仓相关单列）。
- 存储：`data/processed/news/cls_YYYY-MM-DD.json`（仅标题/时间/链接/level/关联股票，**不存正文**，C15）。
- 纯规则、无 LLM。

## 数据源

- 财联社电报：`app/collectors/cls_src.py`（免签名接口 `/api/cache`，约 20 条/次，累积去重）。
- 异动：同花顺 API 特色数据（涨停池/跌停）+ akshare（板块/龙虎榜）。

## 已知限制

- 财联社免签名接口单次仅返回最近约 20 条、无日期参数；「盘后全天要闻」依赖盘中多次「盘中刷新」累积（或未来接定时累积任务）。
