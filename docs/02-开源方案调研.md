# 开源方案调研（GitHub）

> 目的：为 GRGPZS 的五个模块（信息收集 / 汇总整理 / 简约查阅 / 决策参考 / 复盘）找到可借鉴、可复用、可引用的开源项目。
> 说明：以下均为公开 GitHub 项目，引用链接以调研时检索结果为准；使用前请核对各自 License 与使用条款。

## 六、借鉴策略总结

> **★ M0 阶段只用 akshare 一个源**（C17）；全球数据 akshare 全球接口为主、yfinance 仅代理可用时启用（C14）；财联社为 M0 可选增强（C15）；其余均为后续扩展与降级链（详见各表"与本项目关系"列）。

1. **默认免费、同花顺可选增强**：[akshare](https://github.com/akfamily/akshare)（含 tushare/efinance/baostock）为**默认主源与降级链**（参考 a-stock-data-quant、ashare-mcp 的降级实现）；同花顺生态（官方 [Financial-API](https://github.com/HiThink-Tech/Financial-API) → [thsdk](https://github.com/ygx543/thsdk) → [pywencai](https://github.com/zsrl/pywencai)）注册可用后作为**增强源优先使用**；统一封装 `DataSourceAdapter` 接口；
2. **全球市场主备调换（C14）**：akshare 全球接口为主源，yfinance 仅在代理可用时启用；两源均失败 → 用 T-1 数据并在报头显式标注；
3. **舆情可选接财联社（C15）**：cailianpress-unified 为 M0 可选增强；只存标题/时间/链接/自生成摘要，不分发、不二次发布；是否保留由 read 数据决定；
4. **闭环形态参考 daily_stock_analysis**：数据 → 汇总 → 主报+增量页 → 决策 → 推送，先跑通最小闭环；其 LLM 决策能力可作 M4 Provider 集成候选（≥150 笔交易后评估）；
5. **信号清单自研规则 + 模型接口预留（C7/C12）**：信号规则可解释可复现、逐条可验证命中率；统一 DecisionProvider 接口预留（累计 150 笔交易后评估）；借鉴 AlphaSift 的"留痕 + 后验评估"（对应昨日预测验证 C6）；
6. **复盘参考 replay / stock-fupan**：采用"指数/板块/个股/情绪"四层复盘组织 + 本地 HTML 报告，叠加交易记录归因统计（胜率/盈亏比/纪律分）。

> 所有引用的开源项目仅作设计与代码借鉴，最终实现为本项目自有代码；接入第三方数据时遵守各自 License 与数据使用条款。
