# 评审报告模板

> 自测记录与评审报告均使用本模板。文件名：`F-xx-自测.md` / `F-xx-评审.md`（多轮加后缀 `-第N轮`），存放于 `docs/dev/reviews/`。

---

```markdown

- 功能点：F-xx
- 自测轮次：第 N 轮
- 日期：

## 开发规格逐条核对

| 规格项 | 完成 | 说明/证据 |
| --- | --- | --- |
| （复制开发规格的每一条） | 是/否 | 文件路径或运行输出片段 |

## 自测清单执行记录

| 自测项 | 结果 | 证据（命令与输出摘要） |
| --- | --- | --- |
| | | |

## 遗留问题与风险

- （无则写"无"）
```

---

## 结论判定标准

| 结论 | 标准 |
| --- | --- |
| 通过 | 四级检查全部"是"，证据完整 |
| 打回 | 任一检查项为"否"（附问题清单） |
| 带条件通过 | 主体正确，存在只能运行时验证或需用户确认的项（附条件清单） |
