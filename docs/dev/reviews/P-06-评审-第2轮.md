- 非阻塞性备注（不影响结论）：
  1. **schtasks"上次结果"掩蔽（可选加固）**：bat 最终退出码 = 最后执行的 powershell 通知的退出码；python 失败（非 0）但通知成功（0）时，任务在 Task Scheduler 显示"上次结果 0"。通知本身已送达用户，满足"失败通知"要求；如需在任务计划程序保留失败状态，可在 python 行后 `set RC=%errorlevel%`、if 块后 `exit /b %RC%`。
  2. **编码健壮性（可选加固）**：bat 为 UTF-8 无 BOM；本环境实测 cmd 按 UTF-8 读取（判别性字节测试），中文通知参数无损；若用户机器 cmd 代码页行为不同（旧系统/英文 cp437），建议 bat 首行 `chcp 65001 >nul` 或通知文本改 ASCII。
  3. **notify_failure.ps1 无 try/catch**：无交互桌面会话时 ShowBalloonTip 可能失败（powershell 退出非 0，不影响 bat 主流程）；与 P-01 notify_desktop 同模式，P-01 评审已记录该环境局限。
  4. 临时脚本 `scripts/_selftest_p06.py` 按约定于本功能点通过后删除；第 1 轮评审产物 `P-06-评审.md` 保留作为打回历史。
