## 遗留问题与风险

- note 命令的 --date 为测试注入参数（生产不用）；盘前计划不校验当日是否交易日（用户自行判断，F-10 后可由日历辅助提示）。
- 计划与成交的匹配规则为"同日同代码同方向"（无 --plan-id 强关联）；若当日同代码同方向多次成交，均视为按计划（M0 简化，样本闸门后如失真再收紧）。
- `scripts/_selftest_f07.py` 为临时自测脚本，评审通过后删除。
