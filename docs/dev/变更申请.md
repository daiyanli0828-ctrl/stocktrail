| 字段 | 内容 |
| --- | --- |
| 编号 | CHG-001 |
| 提出方 | v4-pro（F-03 评审第 1 轮） |
| 关联功能点 | F-03 |
| 企划条款 | 02 规格 F-03"除权日（adj_close 与前收不复权价差 > 阈值）跳过涨跌幅检查" |
| 问题描述 | 规格原文公式在**后复权**刻度下恒成立（adj_close = close × F，F 随分红累计远大于 1）：正常日 \|adj_close − 前收 close\| 也远超任何价格阈值 → 恒判除权 → 恒豁免 → 涨跌幅检查对任何分过红股票失效。公式退化、不可执行。 |
| 建议方案 | 改为**分歧公式**（实现已采用，评审裁定符合 D1 意图）：当日 \|adj 日变动% − close 日变动%\| > 0.5% → 视为除权日，跳过涨跌幅检查。正常日分歧≈0；除权日分歧≈股息率。刻度无关、仅需 close/adj_close 两列。 |
| 影响面 | docs/dev/02 F-03 规格公式原文 → 修正为分歧公式；代码实现不变（app/quality/checks.py 已正确）；config 注释已同步 |
