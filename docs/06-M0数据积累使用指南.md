# M0 数据积累使用指南

> 目的：帮助日常使用本工具积累 M0 退出评审所需数据（连续 20 个交易日 + read 记录 + 交易留痕）。
> 依据：企划 v1.0 §2.10 C5、§2.12 验收标准；docs/dev/02 M0 功能点规格。

## 〇、最省事的方式：本地网页界面（P-13，推荐）

不想记命令？启动一个本地网页，浏览器里点按钮即可看日报、录交易、记价值验收：

```powershell
python scripts/web_ui.py          # 启动后打开 http://127.0.0.1:8000
```

- 首页：日报列表 / 盘前增量页 / 快速记录入口 / 统计
- 录入盘前承诺与交易理由、记录"今天哪段有用"、看跳过率与命中率——全部网页表单操作
- 仅本机可访问（127.0.0.1），无需登录

> 命令行方式见下方 §一~§三，网页界面与其等价（同一数据库），可混用。

## 一、每日操作流程（5 分钟/天）

### 盘前（约 07:30，交易日）

```powershell
# 1. 盘前增量附页（隔夜美股/A50/日经 + T-1 降级标注）
python scripts/daily_increment.py

# 2. 盘前预先承诺（10 秒：今天打算买什么/为什么/目标/止损）——C3 主入口
python scripts/note.py buy 600519 --reason 趋势 --target 1700 --stop 1500 --note "突破平台"
#    · 无计划的交易 = 非计划交易，会拉低"按计划执行率"（C1.4 行为指标）
```

### 盘中（可选）

```powershell
# 止损守护（每 5 分钟检查设了止损的持仓，跌破→桌面通知一次）——C10 唯一例外
python scripts/stop_watch.py --once        # 单次（计划任务模式）
python scripts/stop_watch.py --loop        # 常驻轮询（手动守护）
```

### 盘后（约 19:00，交易日）

```powershell
# 3. 晚间主报（默认同花顺源，失败自动降级 akshare）
python scripts/run_daily.py

# 4. 成交录入（带理由；T+1 后锁定）
python scripts/note.py buy 600519 --price 1510 --shares 100 --reason 趋势
#    · 若当时没填理由：24h 内可补录（note reason <id>），超 24h 标 post_hoc 会从归因样本剔除

# 5. 热点结论（可选，P-02：生成带预测的板块结论供次日验证）
python scripts/hotspot_conclusions.py
#    或在 data/inputs/conclusions.yaml 手写当日结论（prediction 必填）

# 6. 价值验收（每天必做！C5：读完后记录"哪段有用"）
python scripts/read.py 市场概况 有用
python scripts/read.py 账户体检 没用
#    · 段落名六选一：市场概况 / 账户体检 / 自选异动 / 昨日验证 / 明日计划 / 交易频次
```

### 次日盘后

```powershell
# 7. 昨日验证（判定昨日结论是否命中；判据事前锁定在 verify_rules.yaml）
python scripts/verify_yesterday.py
```

## 二、每周/每月

```powershell
# read 价值验收统计（跳过率 > 50% 的段落将删除——C5 第 8 条）
python scripts/report_read.py --days 20

# 预测命中率报告（P-02；对比 20 日基线）
python scripts/report_hits.py --days 30

# 交易频次/纪律（F-06 已含在日报；P-03 纪律周报待数据 ≥1 个月后开发）
python scripts/note.py verify --date YYYY-MM-DD
```

## 三、数据积累目标（M0 退出评审依据）

| 指标 | 目标 | 来源 |
| --- | --- | --- |
| 连续 20 交易日生成成功率 ≥ 90% | run_daily 每天成功产出 daily.md | data/processed/vault/ |
| 每日有 read 记录 | 每交易日至少 1 条 read（推荐 3-5 条） | notes(kind='read') |
| 每笔交易有盘前承诺或理由 | 提高"按计划执行率" | note 命令 |
| 前瞻结论带 prediction | 每次结论必填 direction/target_scope/deadline | conclusions.yaml |

## 四、注意事项

- **输入文件**：`data/inputs/`（watchlist / positions / trades.csv / conclusions）更新后次日日报自动生效。
- **理由三类**：趋势 / 事件 / 情绪（恰 3 类，C4）；CSV 对账不写理由（C19）。
- **数据质量**：日报底部"数据质量"标注；异常会被拦截并记录，不需人工处理。
- **凭证安全**：config/secrets.yaml（同花顺/DeepSeek key）勿提交公开仓库；建议定期轮换。
- **合规**：仅个人自用；财联社类灰色数据不上云、不分发（C15）。
