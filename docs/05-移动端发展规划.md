# 移动端（Android / iOS）发展规划

> 提案文档（非实施基线）：用户提出最终目标是安卓 + iOS 端软件形式。本规划从现有本地工具出发，
> 给出渐进路线。**任何实施均须先走变更申请（推翻/修订企划 C9、架构 §9）并经用户批准。**

## 1. 目标形态

最终：用户手机上查看晚间主报 / 盘前增量页 / 账户体检、接收止损提醒推送、录入 note（盘前承诺）/ read（价值验收）。
移动端 App 是"云端服务 + 多端前端"架构的一个前端；**云端 API 是网页 / 安卓 / iOS 共用的后端**。

## 2. 总体架构

```
[本地采集 run_daily / daily_increment]          ← 数据源保持在本地可信网络
        │ 同步产物（daily.md / 增量页 / 快照）
        ▼
[云端 API 服务（FastAPI）]  ← 鉴权：令牌/密码（CHG-006 已选）
        ├── Web 网页（H5，Jinja2/Vue，只读展示——CHG-006 已选）
        ├── Android App（Capacitor 套壳 / 原生）
        ├── iOS App（Capacitor 套壳 / 原生）
        └── 推送（FCM for Android / APNs for iOS）← P-01 止损提醒移动化（C10 唯一例外）
```

## 3. 渐进路线（从现有基础出发，分 5 阶段）

| 阶段 | 内容 | 复用资产 | 交付 |
| --- | --- | --- | --- |
| **P0 当前** | 本地工具稳定运行（M0 + P-01/02/06 + P-12 同花顺主源） | — | 本地闭环 |
| **P1 云端服务 + 网页** | 启动 CHG-006：FastAPI + Jinja2 渲染 daily.md → HTML；本地产物同步云端（git/rsync）；Nginx + HTTPS + 令牌鉴权 | Python、Jinja2、现有渲染逻辑 | 手机浏览器可看日报（移动端的第一步） |
| **P2 移动端 Web/PWA** | 响应式 H5 / PWA（可安装到手机桌面、离线缓存） | P1 的 API + 前端 | 手机"类 App"体验，验证使用场景 |
| **P3 套壳 App** | Capacitor 打包同一套 H5 → Android APK + iOS App；本地存储（Keychain/Keystore）存令牌 | P2 的 H5 全部复用 | 双端正式 App |
| **P4 原生增强（可选）** | 推送通道（FCM/APNs）、离线通知、性能关键页原生/Flutter 重写 | 按 P2/P3 真实使用数据决定 | 完整体验 |

**关键判断**：P3 套壳（Capacitor）成本远低于 Flutter/原生重写，且**行为护栏（C1）在 H5 层即可统一实施**，原生重写会引入双端护栏实现偏差风险。除非 P2 数据显示性能/体验是瓶颈，否则停在 P3 是合理终态。

## 4. 关键组件与选型

| 组件 | 选型 | 说明 |
| --- | --- | --- |
| 后端 API | FastAPI（Python） | 与现有代码同语言，复用数据/渲染逻辑 |
| 前端 | H5（原生 JS 或 Vue CDN）→ Capacitor 套壳 | 一套代码双端；无前端构建链起步 |
| 推送 | FCM（Android）/ APNs（iOS） | P-01 止损提醒的云端最终形态；需要云服务器 + 平台证书 |
| 鉴权 | 令牌（Bearer）/ 密码登录 | CHG-006 已选；移动端存 Keychain/Keystore |
| 部署 | 云服务器 + Nginx + HTTPS | CHG-006 已选数据流（本地采集→云展示） |
| 数据同步 | git / rsync / 对象存储 | 本地产物推到云端 |

## 5. 行为护栏在移动端的延续（硬性）

- 交易频次行、无标的清单（C1.1/C1.2）、"今日无需操作"正常渲染（C1.3）——**移动端 UI 同样强制**；
- 止损提醒推送措辞：执行用户过去的决定，无新建议（C10 唯一例外）；
- 移动端推送是**新增的盘中触达通道**，须走变更申请确认（C10 边界复核）。

## 6. 风险与成本

| 项 | 说明 |
| --- | --- |
| App 商店审核 | iOS App Store 审核、国内安卓多渠道分发（应用宝/华为/小米等） |
| 推送 | 需云服务器 + FCM/APNs 证书/密钥（Apple 开发者账号 $99/年） |
| 数据合规（C15） | 云上只放脱敏展示数据；持仓/止损/交易敏感数据须鉴权 + 加密；财联社等灰色数据不上云 |
| 数据源 IP 限制 | 本地采集规避（CHG-006 已选）；云端不直接跑采集 |
| 成本 | 云服务器 + 可能的开发者账号 + 推送通道 |
| 隐私 | 移动端含持仓/交易数据，须本地加密 + 可远程注销 |

## 7. 前置决策（启动移动端前必须拍板）

1. **移动端核心场景**：只看日报？还是要推送止损提醒 / 录入 note / read？（决定 P2 优先级）
2. **是否启动 CHG-006（云端服务）**：云端服务是移动端的前提，本规划 P1 即 CHG-006。
3. **跨平台技术**：Capacitor 套壳（推荐，低成本）vs Flutter（重写，体验更好）。
4. **企划修订**：C9 修订为"本地优先 + 可选云部署 Web/移动端展示"（v1.1）。
